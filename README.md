## Air-travel-data-analysis
Анализ данных авиаперевозок и факторов доминирования выручки.
#### Описание проекта:
Цель проекта - исследовать структуру выручки авиакомпании, выявить сезонность спроса и особенности ценовой политики.
#### Данные: 
- В исследовании использовался датасет, содержащий информацию о продаже авиабилетов; каждая строка - уникальная покупка. Объем датасета - 50.000 строк.
- Данные включают характеристики покупки: дата покупки, дата совершения перелета, тип пассажира, сумма, направление перелета, тип перелета, использование программы лояльности, способ покупки.
- Дополнительно использовались данные с кодами аэропортов, содержащие информацию о наименовании аэропорта, стране расположения, коде по системе IATA и по системе ICAO, широта и долгота (https://raw.githubusercontent.com/jpatokal/openflights/master/data/airports.dat)
#### Используемые инструменты:
Python (NumPy, Pandas, Matplotlib, Seaborn, SciPy)
#### Этапы анализа: 
1. Загрузка и предобработка данных;
2.  Исследовательский анализ данных:

    - Создание отчета о динамике продаж;
    - Исследование сезонности продаж;
    - Классификация клиентов в зависимости от времени покупки авиабилета и проверка гипотезы о том, что выручка по группам клиентов различается;
    - Определение топ-10 популярных направлений перелета;
    - Корреляционный анализ зависимости выручки от других признаков.
#### Основные результаты: 
1. Структура бизнеса и рынок: 91% выручки генерируется внутренними перелетами, что подтверждает ориентацию компании на российский рынок.
2. Сезонность и динамика спроса: летний период демонстрирует пиковые показатели выручки (+18% корреляция), зимний сезон характеризуется снижением доходности (-14% корреляция).
3. Ценовая политика и стратегия:
   
   - Динамическое ценообразование подтверждено статистически: билеты, купленные в последний момент (0-7 дней до вылета), стоят дороже;
   - Offline-продажи приносят на 16% больше выручки по сравнению с online;
   - Топ-маршруты демонстрируют разную стратегию: Москва-Санкт-Петербург: стратегия низких цен для максимизации объемов, Новосибирск-Сочи: высокий средний чек, вызванный длинными перелетом, Международные направления: асимметричное ценообразование (дороже из-за рубежа в Россию).

4. Клиентская база и программы лояльности: взрослые пассажиры составляют основу клиентской базы, детский сегмент важен для формирования семейной лояльности, текущая программа лояльности неэффективна и требует пересмотра, категории клиентов по времени покупки статистически значимо различаются по вкладу в выручку.
5. География и маршрутная сеть:

   - Лидирующие направления: Сочи-Москва и Москва-Сочи по объемам продаж;
   - Максимальный средний чек: Новосибирск-Сочи (курортное и дальнее направление);
   - Международные направления показывают устойчивый спрос с Ошем и Худжандом.
